# NOVA – AI-Powered Intelligent Personal Assistant

NOVA is a Python-based intelligent personal assistant developed using Natural Language Processing (NLP), voice recognition, web information retrieval, summarization, automation, and a PyQt5 graphical user interface.

It accepts both voice and text commands, understands the user's request, performs the appropriate task, and provides responses through voice and the graphical interface.

## 🎯 Objectives

- Provide voice and text-based interaction.
- Understand natural language commands.
- Perform question answering and information retrieval.
- Search and summarize information from the web.
- Automate Google, YouTube, and Windows tasks.
- Monitor battery and charger status.
- Provide an interactive desktop GUI.
- Combine multiple assistant capabilities into one system.

## ✨ Key Features

- 🎙️ Voice interaction
- 💬 Text-based interaction
- 🧠 NLP-based intent classification
- 🔎 Deep web search and summarization
- 🌐 Google and website automation
- ▶️ YouTube automation
- 💻 Windows task automation
- 🔋 Battery and charger monitoring
- 👏 Two-clap random music trigger
- 🖥️ PyQt5 graphical interface
- 💬 Conversation history
- 🔵 Animated NOVA Orb
- 📊 Voice activity waveform
- 🔊 Text-to-Speech responses
- 🔄 Real-time assistant status updates

## ⚙️ How NOVA Works

```text
User Voice / Text Command
          ↓
Speech Recognition
          ↓
NLP / Text Processing
          ↓
Intent Classification
          ↓
Appropriate NOVA Module
          ↓
Information Retrieval / Automation
          ↓
Response Generation
          ↓
Backend–UI Bridge
       ↙       ↘
   PyQt5 GUI    TTS
       ↓         ↓
Visual Response  Voice Response
````

## 🧩 Major Modules

### Brain

Handles command understanding, intent processing, and decision making.

### Voice & Speech

Handles listening, speech recognition, and text-to-speech responses.

### Deep Search

Searches web information, extracts relevant content, and generates summaries.

### Automation

Performs Google, YouTube, Windows, and other supported automated tasks.

### Battery Monitoring

Monitors battery percentage and charger status.

### Clap Detection

Detects two claps and triggers random music.

### Interface

Provides the PyQt5 graphical user interface for interacting with NOVA.

### Backend–UI Bridge

Communicates events and responses between the NOVA backend and the PyQt5 interface.
